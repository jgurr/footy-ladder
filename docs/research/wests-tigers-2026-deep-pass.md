## Short Answer

Top 30 confidence is **medium, around 68/100**.

The roster names are credible as a working NRL roster, but the exact Top 30 status is not clean enough for a polished UI yet. Wests Tigers' own tracker lists an "NRL Squad" and a separate "NRL Development List", and a few names appear in both contexts. The NRL tracker gives a current Wests Tigers contract table, but it does not fully resolve Bunty Afoa/Javon Andrews/Development List treatment.

Salary confidence improved materially after the credentialed source pass:

- Daily Telegraph / Code Sports published individual Wests Tigers roster values for **17 players** in its 2026 NRL Rich List / roster-value investigation.
- Those values should be labelled as **published media roster valuations**, not official NRL cap ledger salaries.
- One separate SMH salary report found: **Sione Fainu, three years / $1.1m**, which is best treated as a 2027-2029 extension AAV of about **$367k**, not a clean 2026 number.
- Adam Doueihi has a reported older **$150k near-minimum offer**, but that relates to a previous short-term negotiation, not his current 2026-2029 extension.
- For the remaining players, the Daily Telegraph article either groups them in "the rest" bucket or omits them, so no direct individual number should be retained.
