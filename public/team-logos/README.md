# Official NRL team badges

These assets are downloaded from the official [NRL clubs directory](https://www.nrl.com/clubs/)
via `npm run refresh:team-logos`.

- `badge-24.svg` is the NRL `badge-basic24` variant used at 24px and below.
- `badge.svg` is the complete NRL club badge used above 24px.

Last refreshed: 2026-09-03. Club names, logos, and trademarks belong to their respective owners.
